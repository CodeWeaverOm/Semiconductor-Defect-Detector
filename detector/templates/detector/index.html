About the model

The detector is an image classifier built on a ResNet convolutional network (exported from PyTorch to ONNX). It looks at the texture and shape of the pattern in the image and assigns it to one of {{ num_classes }} classes.

  • Input images are converted to 3 channels, resized to 224×224 and normalised.
  • The network outputs one score per class; a softmax turns them into probabilities.
  • The model is loaded once when the server starts and reused for every request.
  • Uploaded images are analysed in memory and are not stored.

Pipeline

Image→Resize 224²→ResNet→Softmax→Defect class
